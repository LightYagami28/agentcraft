# Security Policy

## Supported Versions

Security fixes are applied to the tip of `main` in this fork.

| Version | Supported |
| --- | --- |
| `main` (this fork) | :white_check_mark: |
| Earlier snapshots | :x: |
| Upstream blendi-remade/agentcraft | :x: (report here first) |

## Reporting a Vulnerability

Do not open a public issue for a security problem. Email
<developer@lightyagami.dev> with:

- the affected component and the revision you tested;
- reproduction steps and a proof of concept, if you have one;
- the expected impact and a possible mitigation.

You should receive an acknowledgement within five working days. We will keep
the report private, work on a fix in this fork and inform you before public
disclosure. Please allow time for a fix before publishing the details.

If the issue is inherited from upstream, we will forward the relevant details
privately. Do not open pull requests against upstream without prior approval.
